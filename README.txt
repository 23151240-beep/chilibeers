CHILIBEERS — CÓMO PUBLICARLO GRATIS

1) Abre index.html para probar la página.
2) Antes de publicar:
   - En script.js cambia pedidos@chilibeers.example por el correo que usarás.
   - En index.html cambia href="#" del botón de Instagram por el enlace de tu cuenta.
   - Ajusta sabores, precios y datos a los reales.
3) GitHub Pages:
   - Crea un repositorio público en GitHub.
   - Sube index.html, style.css, script.js y la carpeta images.
   - Ve a Settings > Pages.
   - En Build and deployment elige Deploy from a branch.
   - Selecciona main y /(root), luego Save.
   - GitHub te mostrará el enlace público.

No necesitas pagar hosting ni comprar dominio para el proyecto básico.
